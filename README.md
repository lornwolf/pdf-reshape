# PDF 整形

扫描书籍 PDF 的整形工具：**纠正页面倾斜**，并把**版心（正文）移到页面正中**。

- 自动检测每页的倾斜角度并转正，横排、竖排通用
- 参照全书的标准版心对齐：章末半页、没有页眉的页、整体缩进的页不会被错误地居中
- 自动排除扫描黑边、空白处的污渍、挂在正文外侧的页码对版心判断的干扰
- 尽量不损失画质：直接取用 PDF 内嵌的原图；不需要旋转的页只做整像素平移（JPEG 按编码块对齐）
- 显示增强：对能有明显改善的黑白页自动选方法（低分辨率的页放大平滑、杂质多的页去噪点、大字页矢量化），网点图案原样保护；预览里按住鼠标是放大镜
- 文字书 / 漫画书两种类型：漫画有「纸面找平」（把纸面按当地纸色拉白，去掉订口的灰影，网点和墨线不动），不做黑白页的增强
- 分析后按书的类型给出参数建议（不旋转角度、JPEG 质量、是否找平等），并预估输出文件的大小
- 梯形校正：扫成梯形的页，按「梯形校正」后拖四个角围住版心，「执行校正」把它拉成矩形铺满整页；「取消校正」恢复原样
- 逐页可以指定「本页不修正」「删除当前页」「去除边缘污染」，可以手动微调版心边框（用鼠标拖红框上的小方块，或用箭头按钮一步步调；调好后点「版心居中」页面才按新的红框对齐），或让它「与前页/后页相同」
- 校正进度保存在 SQLite 数据库里，下次打开同一本书直接恢复（按文件内容识别，改名、挪位置也认得）

不做书脊弯曲（dewarp）之类的复杂修正。

## 安装

需要 Python 3.12 以上。

```
pip install -r requirements.txt
```

图形界面只用到 Python 自带的 tkinter，不需要别的库。

## 使用

### 图形界面

Windows 下双击 `PDF整形.bat`（也可以把 PDF 拖到它上面），或者：

```
python pdf_reshape_gui.py [书.pdf]
```

打开文件后会在后台分析全书，左右对照预览每一页处理前后的效果；确认后点「开始处理」。
输出文件默认是 `原文件名（校正版）.pdf`，原文件不会被改动。

键盘翻页：方向键、PageUp / PageDown、Home / End。

### 命令行

```
python pdf_reshape.py 书.pdf [-o 输出.pdf] [--pages 1-20] [--skip-pages 3,8] [--delete-pages 1,2]
                             [--cleanup-pages 4,7] [--enhance] [--clean-margin] [--upscale] [--min-angle 0.3] [--quality 70]
                             [--book manga] [--flatten]
```

| 选项 | 作用 |
|---|---|
| `--pages` | 只处理指定的页（试效果用） |
| `--skip-pages` | 这些页不做修正，原样保留 |
| `--delete-pages` | 这些页不输出到新 PDF |
| `--cleanup-pages` | 这些页去除版心以外的边缘污染（按周围干净的纸面重新画上） |
| `--clean-margin` | 版心外去污染：全书的黑白页都去掉版心外的黑边、污渍（灰度/彩色页不动；逐页的用 `--cleanup-pages`） |
| `--enhance` | 显示增强：只增强能明显改善的黑白页，方法自动选择 |
| `--upscale` | 黑白二值页旋转时以 2 倍分辨率输出，笔画边缘更平滑 |
| `--book` | 书的类型：`text` 文字书（默认）/ `manga` 漫画书。漫画可用 `--flatten`，不用 `--enhance`/`--upscale` |
| `--flatten` | 纸面找平（漫画）：把灰度页的纸面按当地纸色拉白，去掉页边的灰影（订口阴影） |
| `--min-angle` | 小于此角度不旋转（不指定则自动采用建议值） |
| `--quality` | JPEG 质量（不指定则自动采用建议值） |

## 已知局限

- 输出是纯图像页：原 PDF 若带 OCR 文字层，被修正的页会丢失文字层（可在处理后用 `ocrmypdf` 重新识别）。目录书签和元数据会保留。
- 原扫描就把文字切到边缘的页无法复原，只会按可见内容居中。
